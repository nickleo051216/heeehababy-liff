# 插畫圖檔放這裡

前台會自動讀這幾個檔名。有檔案就顯示圖；沒有檔案就顯示淡色圓形加 emoji，不會破版。

| 檔名 | 用在哪裡 | 建議尺寸 |
|---|---|---|
| `mascot-dog.png` | 首頁「照片喊單」卡右邊（拿相機的小狗、吊衣架上的黃色吊帶褲） | 240 × 240，透明背景 |
| `mascot-bunny.png` | 「大家的許願樹」標題左邊的小兔子 | 120 × 120，透明背景 |
| `mascot-bear.png` | 「每日連線＋1」標題左邊抱籃子的小熊 | 160 × 160，透明背景 |
| `tree.png` | 許願樹整張背景（手繪感的綠色大樹） | 寬 800 以上，可以是透明背景 |

### 備用角色（目前程式還沒用到，之後可以直接引用）

| 檔名 | 角色 |
|---|---|
| `mascot-goose.png` | 戴帽子、提包裹的鵝（適合出貨、寄送） |
| `mascot-squirrel.png` | 拿筆記本的松鼠（適合對帳、記帳） |
| `mascot-chick.png` | 抱鉛筆的小雞（適合填表、備註） |
| `mascot-cat.png` | 坐在墊子上的貓（適合空狀態、休息中） |
| `mascot-strawberry.png`、`mascot-leaf.png`、`mascot-stamp.png` | 小裝飾：草莓、葉子和星星、郵票 |

圖檔來源：周小姐提供的示範站原始檔（2026-11-25），已去背、裁邊、壓縮。

換圖時只要把同名的檔案放進這個資料夾，不用改程式。
